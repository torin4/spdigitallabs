How to copy Mac screenshots to the clipboard, and find one later by the text in it

14 November 2026 · 4 min read

Mac app · Coming soon

Tuck

A clipboard manager for Mac that stays out of sight. It remembers the text, files, images and screenshots you copy, and nothing leaves your Mac.

See Tuck

Most screenshots are used once: pasted into a message or a document and never opened again. macOS still saves each one as a file on the Desktop. You can send them to the clipboard instead, and with a clipboard history you can still find one later.

Where screenshots go by default

Unless you've changed it, every screenshot is saved to the Desktop as a file named with the date and time. That's right for a screenshot you want to keep. For one you only want to paste somewhere, it means an extra step now, dragging the file in, and a file to delete later.

Copy one screenshot to the clipboard

Add the Control key to any screenshot shortcut and the picture goes to the clipboard instead of a file. Then press Cmd+V wherever you want it.

Screenshot shortcuts that copy to the clipboard
CapturePress
The whole screenCmd+Ctrl+Shift+3
An area you drag overCmd+Ctrl+Shift+4
One windowCmd+Ctrl+Shift+4, Space

Without Control, the same shortcuts save a file as usual.

For a window, press the shortcut, then Space, then click the window you want.

Make the clipboard the default

If you paste most of your screenshots, you can stop macOS creating files at all:

  • Press Cmd+Shift+5 to open the screenshot toolbar.
  • Click Options.
  • Under "Save to", choose Clipboard.

From then on, the ordinary shortcuts, Cmd+Shift+3 and Cmd+Shift+4, copy to the clipboard and nothing lands on the Desktop. The setting stays until you change it back in the same menu.

If you'd rather keep files but not on the Desktop, the same menu has Other Location, where you can pick a folder for screenshots.

The catch: the clipboard holds one thing

A screenshot on the clipboard is not saved anywhere. Copy anything else, even a single word, and the screenshot is gone. So is the one you took just before it, if you took two in a row.

That's fine for a screenshot you paste within the next few seconds. For anything you might want again, either save it as a file or use a clipboard history, which keeps each copy in a list. What a clipboard manager is, and who needs one on a Mac explains how a history works.

Finding a screenshot later

Screenshot files are named by date, so the Finder can show you the one from Tuesday afternoon, if you remember it was Tuesday afternoon. What you usually remember is what was in it: an error message, an order number, a name.

macOS can read text in pictures. Open a screenshot in Preview and you can select and copy the words in it, like text in a document. That helps once you've found the right file. It doesn't help you find it among two hundred others.

A clipboard history that reads the text in each image as it arrives does. You type a word that was on screen, and the screenshots containing it come up.

Doing it in Tuck

Tuck is a clipboard manager for Mac that isn't released yet; it's coming to the Mac App Store. It keeps images as well as text, and it reads the text in them.

Getting screenshots into Tuck

Tuck records any image that reaches the clipboard. So the Control shortcuts above, and the "Save to: Clipboard" setting, work with no setup: every screenshot you copy is added to your history.

If you prefer to keep saving files, Tuck can pick those up too. In Settings > General, under Screenshots, click Choose Folder and select the folder macOS saves screenshots to, usually the Desktop. New screenshots saved there are then added to the history. The file stays where it is, and Tuck only reads the folder; it has no permission to change it. Screenshots that were already in the folder are not imported, and screen recordings are not added.

Finding one

Press Cmd+Shift+V to open Tuck and type words that appear in the screenshot. Every word you type must be in the image's text. Type is:image to list only images, on its own or with other words. The selected image is shown under the list, next to the text Tuck found in it.

The reading is done on your Mac by macOS. The image is not sent anywhere; Tuck never connects to the internet.

Using it

  • Return pastes the image into the app you were in. In Terminal and several other terminal apps, which only accept text, it pastes the path to the image file.
  • Shift+Return pastes the text found in the image, which saves retyping an error message or a code.
  • Cmd+P pins the image so it's never dropped.
  • Cmd+Delete deletes it.

Limits worth knowing

  • An image is found only by its text. A screenshot of a photo or an unlabeled chart has no words to search for. You'll find it by scrolling, or by listing images with is:image.
  • Reading takes a moment. A new image appears in the list straight away, but it can't be found by its words until the text has been read. Tuck reads images in the background, one at a time.
  • Text recognition makes mistakes. Very small or decorative text can be misread, and search matches the letters as they were read.
  • Images are dropped sooner than text. Tuck keeps the newest 200 images unless you change the number in Settings > History. Pin the ones you need to keep, or save those as files.
  • Very large images are skipped. An image over 60 MB is not recorded.
  • Screenshots of secrets are not searchable. If the text in an image looks like a password or key, Tuck doesn't keep that text. The image itself stays in your history until you delete it. Is clipboard history safe? has more on this.

The support page covers what to do if screenshots don't appear.
