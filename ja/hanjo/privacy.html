プライバシーポリシー

最終更新日：2026年11月11日

Hanjo（hanjo.app）は、家の間取りを設計できるウェブアプリです。日本の個人開発者 Joseph Suzuki-Parker が屋号「SP Digital Labs」で提供しています（以下「当方」）。本ポリシーでは、Hanjo が取得する情報、その利用目的、提供先、およびお客様が選べることを説明します。

要点：設計はブラウザに保存され、ログインしている場合は、ほかの端末でも開けるようアカウントにも保存されます。AIデザイナーを使うと、作業中の設計とご依頼の内容が、変更案を作成するために Anthropic の AI サービス Claude に送信されます。Anthropic はこれをモデルの学習に使用しません。共有した設計は、共有した相手が見ることができます。広告は表示せず、分析ツールも使わず、データを販売することもありません。AIプランは Stripe を通じて販売され、当方がカード情報を見ることはありません。

取得する情報

アカウント

  • Googleでログインした場合も、メールアドレスとパスワードでログインした場合も、メールアドレスとユーザーIDを取得します。
  • Googleでログインした場合は、Googleから名前とプロフィール画像も受け取ります。これらを他の人に表示することはありません。
  • 当方がパスワードを見ることはありません。ログインサービスを提供する Supabase は、パスワードを安全なハッシュ値としてのみ保存します。

設計

  • 作業内容：家の設計（敷地、階、壁、部屋、ドアと窓、階段、屋根、仕上げ、家具、外構）、その設計に至った編集履歴、保存した版と提案。
  • 下絵：なぞって描くために読み込んだ画像やPDFのページ。
  • これらはブラウザに保存されます。ログインしている場合は、ほかの端末でも開けるよう、アカウントにもコピーが保存されます。
  • 設計には、敷地の大きさ、形、方位が含まれることがあります。住所は必要なく、当方からお尋ねすることもありません。

共有とコメント

  • 設計を共有すると、その設計のコピー、招待した相手のメールアドレスと役割、および寄せられたコメント（それぞれコメントした人のメールアドレス付き）を保存します。
  • 閲覧のみのリンクについては、リンクのコードを変換したもの（ハッシュ値）、有効期限、無効にしたかどうかのみを保存します。

AIデザイナー

AIデザイナーにリクエストを送ると、当方のサーバーが暗号化された通信で、Anthropic の AI サービス Claude に次の情報を送信します。

  • 作業中の設計（その時点のもの）
  • ご依頼の内容、その会話でのそれまでのメッセージ、図面上で選択または印を付けた箇所
  • お使いの言語

Claude による変更は、設計に対する通常の編集として返されます。Anthropic の商用利用規約に基づき、Anthropic は当方が送信した内容をモデルの学習に使用しません。ただし、規約に定めるとおり、不正利用の検知のために一定期間保持することがあります。当方のサーバーはリクエストを中継するだけで、会話を保存しません。プランの利用枠を適用するため、リクエストごとに、使用したモデル、使用したトークン数、費用、日時を記録します。

お支払い

  • AIプランは Stripe の Managed Payments を通じて販売され、Stripe グループの Link が販売事業者となります。お支払い情報は Stripe と Link が直接受け取り、当方が受け取ることはありません。
  • サブスクリプションをお客様のアカウントに結び付けるため、メールアドレスとユーザーIDを Stripe に送信します。また、Stripe の顧客IDとサブスクリプションID、サブスクリプションの状態、請求期間を保存します。

端末とブラウザ

  • ブラウザに保存されるもの：設計と下絵、3Dの設定や時刻などの表示設定、ログイン状態。
  • Hanjo は分析、広告、トラッキングのツールを使用していません。フォントも hanjo.app 自体から配信しています。

利用目的

  • Hanjo の提供（設計の保存、お使いの端末での表示、アカウントの安全の確保）
  • お客様が選んだ相手との設計とコメントの共有
  • ご依頼に応じたAIデザイナーによる変更案の作成と、プランの利用枠の適用
  • サブスクリプションの処理
  • お問い合わせやご依頼への対応

お客様の情報を広告に使うことはなく、販売することもありません。

保存場所と外国への移転

アカウント、設計、共有コピー、コメントは、Supabase の東京リージョンに保存されます。アプリとそのサーバーは Vercel 上で動作しており、そのサーバーはアメリカ合衆国その他の国にあることがあります。AIのリクエストはアメリカ合衆国で Anthropic が処理します。お支払いは Stripe が処理し、データはアメリカ合衆国その他の国で処理されることがあります。アメリカ合衆国には、日本の個人情報保護法に相当する包括的な連邦の個人情報保護法はありません。これらの事業者は、下記のリンク先にあるそれぞれのポリシーと契約に基づき、データを保護することを約束しています。データは通信時と保存時に暗号化されます。

提供先

情報は、Hanjo の運営に必要な次のサービスにのみ提供します。

  • Supabase：アカウントと設計の保存、ログインの処理。Supabase のプライバシー
  • Vercel：アプリの配信とサーバーの運用。Vercel のプライバシー
  • Anthropic：AIデザイナーで使う Claude のモデルの運用。Anthropic のプライバシー
  • Stripe と Link：AIプランの販売と請求。Stripe のプライバシー · Link のプライバシー
  • Google：Googleでログインすることを選んだ場合。Google プライバシーポリシー
  • 設計を共有した相手や、閲覧のみのリンクを渡した相手は、その設計を見ることができます。メンバー同士は、互いのコメントとメールアドレスを見ることができます。

このほか、法令に基づく場合は、情報を開示することがあります。

保存期間

  • アカウントと設計：お客様が削除するか、アカウントを削除するまで
  • 共有コピー、コメント、招待：設計の共有をやめるまで。閲覧のみのリンクは、有効期限が切れるか、無効にするまで
  • AIの利用記録：アカウントを削除するまで
  • お支払いの記録：Stripe と Link が法令に従って保存します

お客様が選べること、お客様の権利

  • 設計の共有はいつでもやめられます。共有をやめると、共有コピー、そのコメント、リンクが削除されます。
  • AIデザイナーを使わずに Hanjo を使えます。リクエストを送らない限り、Anthropic に何かが送信されることはありません。
  • アカウントとそれに保存されたすべての情報を削除するには、アカウントのメールアドレスから当方にメールでご連絡ください。30日以内に削除します。AIプランも同時に解約されます。
  • お住まいの地域によっては、情報の開示、訂正、利用への異議、データ保護当局への申立てなど、さらに権利を持つ場合があります。当方にご連絡いただければ対応します。

お子様について

Hanjo は13歳未満のお子様を対象としておらず、お子様の情報を故意に取得することはありません。お子様が情報を提供したと思われる場合は、当方にご連絡ください。削除します。

本ポリシーの変更

本ポリシーを変更する場合は、冒頭の日付を更新します。重要な変更の場合は、アプリ内でもお知らせします。
