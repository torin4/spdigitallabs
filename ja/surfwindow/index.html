Surf Windowウェブアプリ · 無料

行く価値はある？行くならいつ？

Surf Window は、湘南と千葉の25のサーフポイントについて、最新のうねり・風・潮を各ポイントの特性と照らし合わせて採点します。1時間ごとのスコアと、その理由がわかります。日本語と英語に対応しています。

Surf Window を開くアカウント不要

  • ポイントごとのスコア

    Surf Window は湘南と千葉の25のサーフスポットに対応しています。ポイントごとに、波・風・潮の最新の予報を確かめ、その浜が良くなるために必要な条件と比べます。1時間ごとに100点満点のスコアを付け、何が波を良くしていて、何が妨げているのかを短くわかりやすい一文で伝えます。

  • うねりの入る範囲が見える

    浜はそれぞれ違う方角を向いています。ある方角からの波は届き、それ以外は岬や湾にさえぎられます。Surf Window はこの「うねりの入る範囲」を風と波のライブ地図の上に描くので、今日ある浜に波があり、隣の浜はフラットなのはなぜかがひと目でわかります。

  • 7日間を1時間ごとに

    予報タブでは、この先7日間を1時間ごとに並べます。浜での波のサイズ、波と波の間隔（周期）、風、潮、波のパワーをひとつのタイムラインで確認できます。その週でいちばん良い時間帯も Surf Window が選び出すので、自分で計算する必要はありません。

その他の機能

  • 浜からの報告

    浜にいるサーファーが、実際の様子を3回のタップで報告します。予報の横に表示されます。

  • 危険も正直に

    上級者向けの時間帯には印が付き、どのポイントにも危険についての注意書きがあります。

  • 日本語と英語

    すべての画面が両方の言語に対応しています。アカウントは不要で、現在地はお使いのスマートフォンの中にとどまります。
